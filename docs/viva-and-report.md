# Report and viva preparation

## Suggested 10-page report

1. Title and problem statement
2. Users, scope, and requirements
3. Architecture diagram and request flow
4. MongoDB schema diagram and references
5. Business rule and status transitions
6. API endpoint table and HTTP statuses
7. React Native screens, navigation, and token handling
8. Image upload and validation
9. Vercel/Atlas deployment walkthrough and live evidence
10. One-page reflection on problems and fixes

Follow any course report template if it differs. Include the live URL and environment **names**, with secret values redacted.

## Demonstration sequence

1. Open the installed APK and sign in.
2. Browse API-fed items; search and filter.
3. Post and edit an item with a photo.
4. Sign in as another user and submit a claim.
5. Return as the finder and approve the claim.
6. Show `Returned` and a refused second approval.
7. Show the live health endpoint and Atlas collections.

Prepare to explain references, authentication middleware, JWT storage, transaction and index behavior, HTTP status codes, image persistence, validation, and any declared AI assistance.
