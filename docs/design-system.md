# CampusFind mobile design system

The UI follows the requested blue, orange, and white palette. The UI/UX Pro Max skill's mobile guidance informed its touch sizing, contrast, forms, navigation, safe areas, feedback, and icon use. Its generated rose palette was deliberately replaced by the user's palette.

| Role | Color |
|---|---|
| Deep navigation / hero | `#102A47` |
| Primary blue | `#155CB6` |
| Accent orange | `#E96A16` |
| Accessible orange text | `#B94B0B` |
| White cards | `#FFFFFF` |
| Page background | `#F5F8FC` |
| Primary text | `#142B43` |
| Muted text | `#52677E` |

The app uses a 4/8-point spacing rhythm, rounded cards, a single Ionicons family, 48-point icon targets, visible button feedback, safe-area-aware scrolling, field labels, inline errors, loading feedback, and empty states. Color never stands alone as a claim status: every badge includes text. The light theme is fixed for consistent contrast and presentation.

Primary navigation has four tabs: Explore, My Items, My Claims, and Profile. Item and claim details open in a stack so Android back returns to the prior context. All list and detail content is requested from the API.
